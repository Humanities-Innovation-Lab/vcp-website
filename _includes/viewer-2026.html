The current viewer

This is our most recent working viewer. It brings all three crosses together in a single edition: each cross has a 3D model set beside chapters on its scanning campaign. There is also info on history, connections between crosses, and iconography. The models run in 3DHOP, the open source heritage viewer built by the same ISTI CNR group that scanned the crosses, which streams the multiresolution meshes a piece at a time so a full-resolution monument will load in an ordinary browser.
